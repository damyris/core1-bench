# Core 1 Bench

Quick, ADHD-friendly practice for the CompTIA A+ Core 1 (220-1201) exam.

- `index.html` is the app: layout, styles, and logic.
- `bank.js` is the question bank. Add or edit questions here, or use the in-app editor (in-app edits are saved in your browser; use **Back up / restore** to move them between devices).

Progress is saved in the browser you study in. The site is plain HTML with no build step: edit a file, commit, push, and GitHub Pages updates within a minute or two.
